2026-09-13 사용자 지시로 보존합니다. **이번 기능(상품 매핑·발주정보 부분 저장·재입고 제외)이 운영에서 안정적으로 확인된 다음** 별도 작업으로 진행합니다.
이 문서의 어떤 항목도 지금 구현하거나 배포하지 않습니다.

## 진행 순서 (후속 단계에서 지킬 것)

1. 화면별 버튼 목록, 호출할 DB 함수/API, 권한, 실행 전후 상태를 **표로 먼저 설계해서 보고**
2. UI 시안과 변경 대상 화면 목록 제시
3. mock 데이터로 화면 테스트
4. 운영 배포 전 사용자 확인

## 상품명 표준

형식: **브랜드 + 상품명 + 규격/수량 + 옵션**

예시
- 모노플랫 제습제 500ml 12개
- 모노플랫 제습제 500ml 24개
- 모노플랫 제습제 600ml 36개
- 모노플랫 논슬립 EPP 발판 그레이
- 모노플랫 논슬립 EPP 발판 블랙
- 아가드 베베 높이조절 독서대 1개
- 아가드X돗투돗 아기 세제 1.5L 1개
- 모노플랫 수납함 3단

변경 규칙
- ERP 코드, product_id, SKU, 기존 매핑 키는 변경하지 않음
- 이름 변경 전에 "기존 상품명 → 새 상품명" 전체 매핑표를 먼저 제시
  - 이번 작업에서 이름을 바꾸지 않은 기존 제습제 상품(1G1A-003-01, -S2, -S3, 1G1A-004-01, -S2)도 이 매핑표에 포함
- 부모상품과 세트상품 관계를 화면에서 바로 확인할 수 있게 표시
- 판매·재고·발주·입고·정산 이력이 끊기지 않게 할 것

## 전체 UI 정리 기준

1. 상태, 재고, 추천수량, 발주단위, 원가, VAT, 물류정보를 구역별로 분리
2. 정상·확인 필요·물류정보 입력 필요·재입고 제외·재입고 승인 필요 상태를 색상과 배지로 구분
3. 색상만 쓰지 말고 상태 문구도 표시
4. 긴 표는 핵심 열을 고정
5. 상세정보는 펼쳐보기로 처리
6. 모바일과 일반 노트북에서 가로 스크롤 최소화
7. 기존 기능과 계산 로직은 바꾸지 않음
