# 리버스 전자결재 시스템 (테스트 버전)

주식회사 리버스의 사내 전자결재 웹앱입니다.
빌드 도구 없이 동작하는 **순수 정적 웹앱**이라 GitHub Pages에 올리면 바로 사용할 수 있습니다.

## 주요 기능

- **지출결의서** 기안 작성 → 결재선(1차 → 최종) 순차 승인/반려
- **결재 대기함** — 내 차례인 문서만 모아 보기 (건수 배지 표시)
- **내 기안함 / 전체 문서함** — 검색, 상태 필터
- **제품 마스터** — 제품 등록/수정/삭제, 검색, CSV 내보내기
- **대시보드** — 결재 대기 건수, 이번 달 승인 지출액 등 요약
- **반응형** — PC 중심, 모바일에서도 사용 가능
- **데이터 공유** — 설정 메뉴에서 JSON 내보내기/가져오기

## 데모 계정

로그인 화면에서 선택 (비밀번호 없음):

| 이름 | 역할 |
|------|------|
| 이사원 | 기안자 |
| 박팀장 | 1차 결재자 |
| 김대표 | 최종 결재자 |

같은 브라우저에서 사용자를 바꿔 로그인하면 기안 → 결재 흐름을 끝까지 테스트할 수 있습니다.

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만듭니다 (예: `reverse-approval`)
2. 이 폴더를 push 합니다
3. 저장소 **Settings → Pages → Source**에서 `main` 브랜치 / `/ (root)` 선택 후 저장
4. 1~2분 뒤 `https://<계정명>.github.io/reverse-approval/` 에서 접속

## 데이터 저장 방식 (중요)

- 테스트 단계에서는 데이터가 **각 브라우저의 localStorage**에만 저장됩니다.
  - 즉, 다른 PC/직원과 실시간 공유되지 않습니다.
  - 공유가 필요하면 **설정 → 데이터 내보내기(JSON)** 후 상대방 PC에서 가져오기 하세요.
- 실제 도입 시에는 Supabase / Firebase 같은 백엔드를 붙여 실시간 공유·로그인·권한 관리를 추가하는 것을 권장합니다. (데이터 구조는 그대로 이전 가능하도록 설계되어 있습니다)

## 폴더 구조

```
index.html      화면 뼈대
css/style.css   디자인 (반응형 포함)
js/app.js       전체 로직 (라우팅, 결재 흐름, 제품 마스터, 저장소)
```
