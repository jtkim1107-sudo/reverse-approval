# 리버스 전자결재 시스템

주식회사 리버스의 사내 전자결재 웹앱입니다.
정적 웹앱(GitHub Pages) + **Supabase**(데이터베이스/로그인) 구조로,
모든 직원이 같은 데이터를 실시간으로 공유합니다.

## 주요 기능

- **지출결의서** 기안 작성 → 결재선(1차 → 최종) 순차 승인/반려
- **결재 대기함** — 내 차례인 문서만 모아 보기 (건수 배지 표시)
- **내 기안함 / 전체 문서함** — 검색, 상태 필터
- **제품 마스터** — 제품 등록/수정/삭제, 검색, CSV 내보내기
- **대시보드** — 결재 대기 건수, 이번 달 승인 지출액 등 요약
- **반응형** — PC 중심, 모바일에서도 사용 가능
- **데이터 공유** — 설정 메뉴에서 JSON 내보내기/가져오기

## 데모 계정

로그인 화면에서 사용자 선택 후 비밀번호 입력:

| 이름 | 역할 | 계정 |
|------|------|------|
| 이사원 | 기안자 | lee@example.com |
| 박팀장 | 1차 결재자 | park@example.com |
| 김대표 | 최종 결재자 | kim@example.com |

비밀번호는 관리자에게 문의하세요. 서로 다른 PC/핸드폰에서 각자 로그인해도 같은 문서가 보입니다.

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만듭니다 (예: `reverse-approval`)
2. 이 폴더를 push 합니다
3. 저장소 **Settings → Pages → Source**에서 `main` 브랜치 / `/ (root)` 선택 후 저장
4. 1~2분 뒤 `https://<계정명>.github.io/reverse-approval/` 에서 접속

## 데이터 저장 방식

- 모든 데이터(문서, 제품, 사용자)는 **Supabase 클라우드 데이터베이스**(서울 리전)에 저장됩니다.
- 로그인은 Supabase Auth(이메일/비밀번호)를 사용하며, 로그인한 사용자만 데이터를 읽고 쓸 수 있습니다(RLS).
- `js/app.js` 상단의 publishable key는 공개 가능한 키입니다 (권한은 서버 쪽 RLS로 제어).

## 직원 추가 방법 (관리자)

1. Supabase 대시보드 → Authentication → Users → **Add user**로 계정 생성 (auto confirm 체크)
2. SQL Editor에서 `profiles` 테이블에 이름/부서/직급/결재권한 추가

## 폴더 구조

```
index.html      화면 뼈대
css/style.css   디자인 (반응형 포함)
js/app.js       전체 로직 (라우팅, 결재 흐름, 제품 마스터, Supabase 연동)
```
